# Servidor PTA — Protocolo de Transferência de Arquivos

**Aluna:** Adriana Silva Lima

## Requisitos

- Python 3.8 ou superior (testado com Python 3.12)
- Nenhuma biblioteca externa (apenas a biblioteca padrão do Python)

## Como executar

A partir da raiz do repositório:

    python3 pta-server/server.py

No Windows, use `python` (ou `py`) no lugar de `python3`.

O servidor escuta na porta **11550**. Para encerrar, use `Ctrl+C`.
